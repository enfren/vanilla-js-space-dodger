# Space Dodger

2D dodge + shoot on Canvas. No dependencies.

## Controls
- **← / →** — move
- **Space** — fire
- **R** — restart (after game over)

## Scoring
- Destroy obstacles for points (small = 1, medium = 2, big = 3)
- Obstacles that escape off-screen give no points
